    Cookie Rules

    Customize cookie sensitivity rules. Enter comma-separated cookie names (not values).

    Overlap rule: if a cookie name appears in both lists, the ignored list wins — that cookie will not be flagged as sensitive.

    Examples of sensitive names: session, auth, token, csrftoken

    Examples of ignored names: _ga, _gid, locale, theme
