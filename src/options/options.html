    Cookie Rules

    Customize cookie sensitivity rules. Enter comma-separated cookie names (not values).

    Overlap rule: if a cookie name appears in both lists, the ignored list wins — that cookie will not be flagged as sensitive.

    Examples of sensitive names: session, auth, token, csrftoken

    Examples of ignored names: _ga, _gid, locale, theme

    Lead Radar & Recon Intelligence

    Passively correlates vulnerabilities, auth posture shifts, endpoints, and leak vectors into prioritized, actionable security leads.

    Consent Disclosure & Safety Invariant:

    Deep Mode registers lightweight in-memory hooks inside page execution contexts to observe sink invocations (such as innerHTML, eval), cross-origin postMessage routing, and sensitive token writes to Web Storage. In accordance with ACULYX privacy standards, runtime values are only inspected in-memory to detect token structure; raw payloads and secrets are never persisted or exported.

    Reconnaissance Memory

    ACULYX accumulates discovered unique hostnames, endpoints, and query parameters per origin to build high-signal wordlists and surface attack surface expansion.
